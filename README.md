# Вікторія DinLova

Навчальний Android-застосунок для Samsung Galaxy Tab зі стилусом S Pen. Авторський курс мистецтва, дизайну, колірної теорії та фотографії для дітей 8–10 років.

## Що в додатку

- 28 уроків і 56 творчих вправ із покроковими інструкціями та 56 SVG-прикладами, доступними офлайн.
- 84 авторські завдання для перевірки розуміння (три на урок, по чотири варіанти відповіді з поясненням), спроби можна повторити.
- Питання для рефлексії після кожної роботи, результати тестів та нотатки в батьківському кабінеті.
- Інтерактивне порівняння сприйняття однакового кольору на двох різних фонах.
- 14 перевірених бібліографічних та онлайн-джерел: Cambridge Primary, Getty, National Gallery of Art, Harvard Project Zero, IB PYP, NAEA, MoMA, книговидавництва Yale та Laurence King.
- Майстерня S Pen: чутливість до натиску (якщо підтримується пристроєм), гумка, повернення/повторення, масштабування, фото як фон, резервні копії.

Застосунок є **незалежним авторським проєктом**, не схвалений і не сертифікований Cambridge, IB, Harvard або згаданими музеями. Зовнішні навчальні джерела в бібліотеці надаються як посилання на видавців і установи; повні тексти захищених авторським правом книг у APK не вбудовані.

## Збірка

GitHub Actions автоматично перевіряє файли курсу та компілює тестовий Android APK. Останній APK доступний у [GitHub Releases](https://github.com/PartykaOlha/mystetstvo-bachyty/releases/tag/android-preview).

## Поглиблений навчальний курс · 4.0

В усіх 28 майстер-класах додано: конкретну навчальну мету, три розгорнуті пояснення, словник із трьох визначень, аналіз тематичного мистецького прикладу, практичний дослід із трьома кроками, творче завдання підвищеної складності й три критерії самооцінювання. Орієнтовна тривалість 35–65 хвилин. На сторінках окремих занять є посилання на перевірені музейні оригінали (зовнішні посилання потребують інтернету).

Нові динамічні експерименти: перспектива і горизонт, світло й тіні, композиційний акцент, кадрування, масштаб заголовка. Творчий щоденник і відзначені навчальні критерії зберігаються на планшеті та відображаються у батьківському кабінеті.

**Версія 4.0 має інший Android package ID** `ua.partyka.viktoriadinlova.masterclass`. Вона встановлюється окремо від старих тестових версій, щоб уникнути несумісності підписів Android debug APK. Прогрес зі старої версії не імпортується автоматично.

Методичні орієнтири: Cambridge Primary Art & Design (дослідження, створення і рефлексія), Harvard Project Zero («побачити — подумати — запитати»), Getty Museum (формальний аналіз), National Gallery of Art (елементи мистецтва). Додаток **не є офіційною програмою** зазначених організацій.
